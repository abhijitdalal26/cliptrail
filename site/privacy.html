Privacy policy

Privacy

Last updated 1 November 2026

Short version: the ClipTrail app collects nothing, and this website doesn't track you.

The ClipTrail app

  • No data collection. The apps and the clipd CLI have no telemetry, analytics or crash reporting, and they never contact a ClipTrail server, because there isn't one.
  • Update checks are optional and off until you choose. On the desktop app, ClipTrail can look for a new version, but only if you turn on Check for updates automatically (it asks once, and you can say no) or click Check for updates in Settings. A check is a plain request for a small file on GitHub Releases (github.com), so GitHub sees your IP address like any download; no information about you, your device or your clips is sent. Updates are signed, verified before they run, and never installed without your confirmation. The Android app never checks.
  • Your history stays on your devices. Clips are stored in a data folder on each device (see Data, backup & uninstall). You can delete any clip, or the whole folder, at any time.
  • Sync is between your own devices. If you pair devices, clips travel directly between them over your local network, encrypted end to end. Only devices you paired can read them.
  • No account. There is nothing to sign up for and no personal information to give.
  • Sensitive clips (one-time codes, keys, card numbers) are masked, kept out of search and sync, and deleted after a short time. Copies from password managers are not saved at all.

The Android app, when it ships, uses an accessibility service only to notice that you copied something and read the clipboard at that moment. It doesn't read screen content for any other purpose.

This website

  • No cookies, analytics, trackers, ads or third-party fonts. Everything is served from GitHub Pages.
  • GitHub Pages hosts the site, so GitHub receives the usual request information (such as your IP address) when you visit. See GitHub's privacy statement.
  • The Download page asks the GitHub API (api.github.com) which release is newest, directly from your browser, so it can link the right files. GitHub's privacy statement applies to that request. The answer is cached in your browser's session storage for 15 minutes and discarded when you close the tab.
  • Theme choice. If you switch between light and dark, the choice is saved in your browser's local storage. It never leaves your device.

Questions

Open an issue on GitHub. For anything security-related, please follow the security policy instead.
