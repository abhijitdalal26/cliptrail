Smart actions

Because {{B}} knows what each clip is, it can paste it the way you need it: a link without tracking junk, a colour as RGB, JSON pretty-printed. Actions never change the stored clip; they copy or paste a transformed version.

Where to find them

  • Dashboard: select a clip; the preview pane shows an Actions row with a live preview. The first five are shown inline, the rest under More. Clicking one copies the result.
  • Quick picker: press Ctrl Enter (or → at the end of the search box) to open the action list for the selected clip, then Enter to paste the result into your app.

Only actions that make sense for the clip and would actually change it are offered. A link with no tracking parameters doesn't get "Clean link"; a colour already in rgb() doesn't get "Copy as RGB". Sensitive, file and image clips have no text actions.

Every clip can also be pasted as plain text (Shift Enter), which drops formatting such as fonts and colours from rich text.

Which parameters count as tracking

utm_*, pk_*, wt_mc*, fbclid, gclid, gclsrc, gbraid, wbraid, dclid, msclkid, yclid, twclid, ttclid, li_fat_id, igshid, mc_cid, mc_eid, _hsenc, _hsmi, __hssc, __hstc, __hsfp, hsctatracking, mkt_tok, _ga, _gl, ref_src, ref_url, spm, vero_id, oly_enc_id, oly_anon_id, s_cid; plus si on YouTube and Spotify links and s/t on X (Twitter) links, where those are share trackers.

Turn on Clean links automatically in Settings → Privacy to strip these as you copy, before the link is even stored.

Code and JSON

ActionWhat it does
Prettify JSONRe-indents valid JSON with two spaces. Key order, numbers and string escapes are left exactly as they were.
Minify JSONRemoves all whitespace between tokens.
As Markdown code blockWraps the clip in a fenced block tagged with its detected language, e.g. ```rust. Uses a longer fence if the code itself contains backticks.
DedentRemoves the indentation every line has in common, handy for code copied from the middle of a file.
Trim whitespaceTrims the ends and strips trailing spaces from every line.
 
# Prettify JSON
{"name":"demo","tags":["rust","tauri"]}
# becomes
{
  "name": "demo",
  "tags": [
    "rust",
    "tauri"
  ]
}
