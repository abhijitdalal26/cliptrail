Data, backup & uninstall

Your whole history is one folder on your device. Nothing is stored anywhere else, so backing up, moving or deleting it is just a matter of that folder.

Where your data lives

SystemData folder
Windows%APPDATA%\{{B}} (e.g. C:\Users\you\AppData\Roaming\{{B}})
macOS~/Library/Application Support/{{B}}
Linux~/.local/share/{{B}} (or $XDG_DATA_HOME/{{B}})

The quickest way there: Settings → Storage → Open folder, or run clipd stats, which prints the path.

What's inside

File / folderContents
clips.db (+ -wal, -shm)Your history: text, metadata and the search index (SQLite).
images/Full-size images as PNG.
thumbs/Thumbnails for the timeline.
settings.jsonDesktop app settings.
device_idThis device's random id.
sync.dbSync state: paired devices, the hub's encrypted event log, progress. Only if you use sync.
keys/Sync keys, only where the OS keychain isn't used (Linux, or CLIPTRAIL_KEYSTORE=file). On Windows and macOS the keys are in Credential Manager / Keychain.
{{i:warn}}

The database isn't encrypted at rest yet. It's protected by your OS account, like your browser history. Encrypting it is on the roadmap. Treat backups of this folder as sensitive.

Use a different folder

Set CLIPTRAIL_DATA_DIR before starting the app or CLI to use another folder, for a throwaway test history or a folder on another drive:

# Windows (PowerShell), for the current session
$env:CLIPTRAIL_DATA_DIR = "D:\ClipHistory"
# Linux / macOS
export CLIPTRAIL_DATA_DIR="$HOME/clip-test"

The CLI also takes --data-dir <DIR> per command.

Back up and restore

  1. Quit {{B}} (tray → Quit) so the database is closed and complete.
  2. Copy the whole data folder somewhere safe.
  3. To restore, quit {{B}}, put the folder back in the same place (or point CLIPTRAIL_DATA_DIR at it), and start the app.

Restoring onto a different computer works for your history. For sync, run clipd sync reset there and pair again, because the keys live in the original computer's keychain.

Reset

  • Delete some clips: select and press Del in the dashboard, or clipd delete <id>.
  • Trim old history: set Keep history to 30 or 90 days.
  • Reset sync only: clipd sync reset with the app closed. Clips stay.
  • Start completely fresh: quit {{B}} and delete the data folder. A new, empty one is created on next launch.

Uninstall

  • Windows: Settings → Apps → Installed apps → {{B}} → Uninstall.
  • Linux (.deb): sudo apt remove followed by the package name shown by apt list --installed | grep -i clip. AppImage: delete the file.
  • macOS: drag the app from Applications to the Bin.
  • CLI: cargo uninstall clipd-cli, or delete the clipd binary.

Uninstalling leaves your history in place in case you come back. To remove everything, also delete the data folder above. If you used sync on Windows, you can remove its entries from Credential Manager → Windows Credentials.
