v0.1.0
Unreleased
Alpha · in progress

The first alpha: a Windows and Linux desktop app, the clipd CLI and encrypted LAN sync, with the Android app being built for the same release.

Encrypted sync and smart actions e9c3d7b

  • The desktop app hosts a sync hub on your local network (HTTP + WebSocket, port 47821). Devices pair by QR code: X25519 key exchange, a one-time secret, a matching 4-digit check code, rate-limited.
  • Clip events and images travel in XChaCha20-Poly1305 envelopes. Pins and deletes sync too (last writer wins).
  • Sensitive clips are never synced; synced clips never touch your OS clipboard on their own; synced writes never echo back.
  • Offline outbox, catch-up and reconnect in the client, built to run on Android as well.
  • clipd sync host | pair | run | devices | revoke | status | reset.
  • Settings → Devices with QR pairing, device list and revoke; sync status in the sidebar.
  • Smart actions per kind: clean tracking parameters, Markdown link, URL decode; colour as HEX/RGB/HSL; JSON pretty/minify; Markdown code block; dedent; trim, single line, case changes; phone digits; mailto link.
  • Actions with live previews in the dashboard; Ctrl Enter action list in the picker; optional automatic link cleaning on capture.

Android capture spike 02cd71b

  • A standalone test app to prove copy capture without a custom keyboard: accessibility-triggered capture with a brief focus grab, Quick Settings tile, share target and text-selection action.
  • Measures its own capture rate per signal; no network permission; on-device log encrypted with an Android Keystore key.

Release pipeline 47c44bb

  • Tagging v* builds Windows (.exe, .msi), Linux (.deb, AppImage), experimental macOS (.dmg) and CLI archives into a draft release.

Desktop app 02e5754

  • Dashboard: sidebar with counts per kind and app, search, a day-grouped timeline, calendar heatmap, a preview pane per kind, copy / copy as plain text / pin / delete with undo, light and dark themes.
  • Quick picker on Ctrl Shift Space: Enter pastes into the previous app, Shift Enter pastes plain text, Ctrl 1–9 quick-paste.
  • Tray menu with recent clips, pause capture, start with Windows and settings.
  • Settings: rebindable hotkeys, retention, sensitive-clip lifetime, excluded apps.

Core, capture and CLI fbf1b1f

  • clipd-core: SQLite store with FTS5 trigram search and versioned migrations; a local classifier for eight kinds (tested on 145 samples); dedup; password-manager exclusion; masked, expiring secrets; image thumbnails.
  • Windows capture: event-driven watcher, rich text, images and files, honours the "don't record this" clipboard flags password managers set, paste-back.
  • Linux capture: X11 and Wayland data-control backends.
  • clipd: watch, list, search, show, stats, pin, delete, prune, ingest-text.

Still to come in v0.1

  • The Android app (capture, tile, share menu, pairing).
  • The first tagged release with installers.

Coming later: sync across networks, on-device database encryption, paste stack, snippets, OCR. See the roadmap.
