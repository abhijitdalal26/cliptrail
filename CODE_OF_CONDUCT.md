# Code of Conduct

ClipTrail follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be welcoming, be respectful, disagree on ideas not people, and keep this a place anyone can contribute to. Unacceptable behavior can be reported to the maintainer via GitHub; reports are handled confidentially.
